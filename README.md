# Calculator App 🧮

A **responsive web-based calculator** with a history panel that allows users to perform basic arithmetic operations, save calculations, and track previous results. The app is built with HTML, CSS, and JavaScript and works on desktop, tablet, and mobile devices.

## **Features**

* Perform **basic arithmetic operations**: addition, subtraction, multiplication, division.
* **Special functions**: square (`X²`), half (`x/2`), percentage (`%`).
* **History panel** to store previous calculations.
* **Clear and delete functions**:

  * `AC` – Clears the current input and result.
  * `Backspace` – Deletes the last character in the input.
  * `Trash` – Clears all history.
* **Keyboard support**:

  * `Enter` → Calculates and saves result
  * `Backspace` → Deletes last input
  * `Escape` → Clears current input
  * `Delete` → Deletes history
* Fully **responsive design** for mobile, tablet, and desktop.
* Smooth button animations and modern UI.

## **Responsive Design**

* **Desktop**: Calculator and history panel side by side.
* **Tablet**: Layout adapts to smaller screens; history panel height adjusts.
* **Mobile**: Buttons and screen resize for usability, history panel scrollable.
